# Mockup (interactive test page)

`Studio87-FX-test-page.html` is the interactive mockup of the whole Studio 87 FX line (open it in a browser, pick the plugin tab). It mirrors this plugin's window and DSP; the real plugin editor in `src/` is built from the same panels, knobs and displays. Screenshots used in the manual are in `docs/tour`.

Note: the page renders a short loop offline, so knob changes there take a moment to be heard. The plugin itself responds within one audio buffer.
