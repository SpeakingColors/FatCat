Fat Cat install and use (works fully offline)
==============================================

Windows
  Run windows\FatCat-Setup.exe. It installs the VST3 plugin for all users and a standalone app.
  Windows may show a blue "unknown publisher" screen because the installer is not signed:
  click "More info", then "Run anyway".
  Uninstall: Settings > Apps > Fat Cat.

macOS
  Open macos\FatCat-macOS.pkg. It installs the VST3 plugin and the standalone app.
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Uninstall: delete "Fat Cat.vst3" from /Library/Audio/Plug-Ins/VST3 and the app from /Applications.

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/FatCat-flatpak-25.08.flatpak
     (older runtimes are end-of-life and have no matching plugin extension base on Flathub; use the plain .vst3 below instead)
  3. Restart the DAW and rescan plugins.

Linux, DAW installed natively
  Extract linux/FatCat-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Uninstall: delete "Fat Cat.vst3" from ~/.vst3.

Manual: FatCat-manual.pdf (every control plus recommendations).
Checksums: SHA256SUMS.
